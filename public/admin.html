Dashboard Fitur Baru & Panduan Penggunaan

Berikut adalah daftar fitur baru yang telah ditambahkan ke sistem SS08 Formulir Pencapaian Kerja, beserta panduan penggunaan dan manfaat utamanya.

Tema Mode Gelap (Dark Mode)

Cara Penggunaan:

Klik tombol ikon matahari/bulan yang terletak di pojok kanan atas Topbar Admin (atau di bagian bawah Sidebar karyawan/login). Sistem akan langsung beralih mode dan menyimpan pilihan Anda secara otomatis di browser.

Manfaat Utama:

Mengurangi ketegangan mata saat Admin memantau data di malam hari atau di area gudang yang redup, sekaligus menghemat konsumsi daya baterai perangkat seluler.

Galeri Bukti Foto (Lightbox Preview)

Cara Penggunaan:

Pada tabel submissions atau loader, klik nama file gambar bukti register atau badge lampiran foto. Foto tersebut akan langsung ditampilkan membesar di tengah layar dengan background overlay gelap. Klik tombol silang (×) atau area luar foto untuk menutup.

Manfaat Utama:

Mempercepat peninjauan berkas bukti register foto secara instan tanpa perlu membuka tab baru browser secara berulang-ulang yang mengotori memori perangkat.

Notifikasi Real-time (SSE)

Cara Penggunaan:

Cukup buka halaman dashboard admin. Bila ada karyawan yang mengirimkan submission berstatus pending (melebihi batas kapasitas carian), notifikasi Toast berwarna kuning akan muncul instan di layar disertai bunyi nada bel ringkas. Angka pada menu "Data Submissions" juga bertambah otomatis.

Manfaat Utama:

Menghilangkan kebutuhan admin untuk me-refresh halaman terus-menerus guna memeriksa inputan over-capacity baru, memungkinkan tindakan verifikasi cepat.

Log Aktivitas (Audit Trail)

Cara Penggunaan:

Klik menu "Log Aktivitas" di sidebar kiri admin. Anda dapat meninjau seluruh log tindakan admin. Gunakan kolom pencarian di kanan atas untuk memfilter log berdasarkan nama admin atau jenis tindakan, dan tombol navigasi halaman di bagian bawah tabel.

Manfaat Utama:

Meningkatkan keamanan data dan akuntabilitas sistem. Mempermudah manajemen dalam melacak kronologi perubahan data (siapa yang menyetujui, mengimpor, atau menghapus data dan kapan).

Optimasi Tampilan Mobile

Cara Penggunaan:

Karyawan di lapangan dapat mengakses formulir dengan browser bawaan smartphone mereka. Ukuran tombol input batch, pilihan area, dan layout lampiran foto telah disesuaikan agar mudah dioperasikan menggunakan jempol tangan.

Manfaat Utama:

Meningkatkan kenyamanan kerja staf gudang serta meminimalisir persentase kesalahan ketik atau salah klik saat menginput data pencapaian harian.

Sistem Absensi Karyawan

Cara Penggunaan:

Buka menu "Absensi" di sidebar admin. Pilih tanggal kerja, lalu tandai karyawan yang hadir dengan mengklik kartu nama mereka (berubah warna hijau). Klik tombol "Pengaturan" di pojok kanan atas untuk mengaktifkan kebijakan wajib absen atau menampilkan rekap absensi harian kepada karyawan.

Manfaat Utama:

Mencegah manipulasi input data oleh karyawan lapangan dengan memblokir pengiriman formulir bagi siapa saja yang tidak diabsen hadir oleh admin pada hari kerja tersebut, menjamin keaslian data laporan carian.

Panduan Setup
Cara konfigurasi Google Service Account
  1. Buka Google Cloud Console → Buat project baru atau pilih project yang ada
  2. Di menu kiri: APIs & Services → Enable APIs → cari & aktifkan Google Sheets API
  3. Buat Service Account: IAM & Admin → Service Accounts → Create Service Account
  4. Setelah dibuat, klik service account → tab Keys → Add Key → JSON → download file JSON
  5. Buat spreadsheet baru di Google Sheets
  6. Share spreadsheet ke email service account (dari file JSON: client_email) dengan role Editor
  7. Ambil Spreadsheet ID dari URL: https://docs.google.com/spreadsheets/d/[ID INI]/edit
  8. Tambahkan ke file .env di folder project:
GOOGLE_SHEETS_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms GOOGLE_SERVICE_ACCOUNT_EMAIL=ss08-bot@my-project.iam.gserviceaccount.com GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEv...\n-----END PRIVATE KEY-----\n"
⚠️ Penting: Restart server setelah mengubah file .env agar perubahan diterapkan.
